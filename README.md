# 🚀 LaunchPad – React Landing Page

A simple, modern and fully responsive landing page built with **React** and **Vite**. This project is beginner-friendly and shows the basics of components, state and responsive CSS.

## ✨ Features

- Sticky navbar with a mobile hamburger menu
- Hero section with heading, description and call-to-action buttons
- Interactive button built with React `useState`
- Features section generated from an array using `.map()`
- Footer with the current year
- Smooth animations (fade-in, floating background, hover effects)
- Fully responsive for mobile, tablet and desktop
- No paid APIs and no extra libraries

## 🛠️ Tech Stack

- React.js
- Vite
- JavaScript (ES6+)
- CSS3 (Flexbox, Grid, Variables, Media Queries)
- Git and GitHub

## ⚙️ Installation

Make sure you have Node.js (v20 or newer) and Git installed.

1. Clone the repository
   ```bash
   git clone https://github.com/YOUR-USERNAME/launchpad-landing.git
   ```
2. Go into the project folder
   ```bash
   cd launchpad-landing
   ```
3. Install dependencies
   ```bash
   npm install
   ```
4. Start the development server
   ```bash
   npm run dev
   ```
5. Open http://localhost:5173 in your browser
